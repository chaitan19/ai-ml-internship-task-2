# Dataset attribution

Dataset: IBM HR Analytics Employee Attrition & Performance, listed on [Kaggle](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset). The included CSV was retrieved from a public [GitHub mirror](https://github.com/IamVasil/IBM-HR-Analytics-Employee-Attrition-Performance/blob/main/WA_Fn-UseC_-HR-Employee-Attrition.csv).

The Kaggle listing reports “Database: Open Database, Contents: Database Contents.” This repository retains the source attribution. The raw CSV is in `raw/employee_attrition.csv`; `processed/employee_attrition_clean.csv` is derived from that source. Review the current source page and applicable license terms before redistributing these files elsewhere.

The dataset is a fictional learning sample, not real employee data or a representative census.
